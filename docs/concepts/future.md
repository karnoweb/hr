# آینده

این دامنهها **عمداً داخل `karnoweb/hr` نیستند**. پکیج فعلی Core HR + حضور + حقوق است. گسترش بهتر است package جدا باشد.

برچسب **آینده** یعنی مفهوم شناخته‌شده است ولی implementation و API ندارد.

## دامنه‌های HRMS

### Recruitment — آینده

Job Requisition، Candidate، Application، Interview، Offer، Hiring.

پیشنهاد بعدی: `karnoweb/recruitment`.

### Onboarding — آینده

برنامه ورود، چک‌لیست، مدارک الزامی. الان فقط سند `hire` وجود دارد.

### Offboarding / تسویه نهایی — آینده

مصاحبه خروج، تحویل دارایی، clearance، تسویه آخرین حقوق، قطع دسترسی.  
`terminate()` امروز lifecycle را می‌بندد ولی settlement مالی کامل نیست.

### Performance — آینده

هدف، KPI، دوره ارزیابی، رتبه.

### Training / توسعه — آینده

دوره، مهارت، گواهی، مسیر شغلی، جانشین‌پروری.

### Disciplinary — آینده

اخطار، تخلف، تحقیق، تنبیه. نوع سند `warning` در enum هست ولی دامنه کامل نیست.

### Benefits — آینده

بیمه تکمیلی، طرح مزایا، ثبت‌نام. بیمه تأمین اجتماعی فعلی statutory است نه benefits.

### مأموریت مالی — آینده

پیش‌پرداخت، هزینه سفر، تسویه. مأموریت فعلی فقط حضور/روز است.

### دارایی پرسنلی — آینده

تحویل/بازگشت دارایی، خسارت.

## قابلیت‌های موتور فعلی که کامل نیستند

| موضوع | وضعیت |
|--------|--------|
| Recalculation کامل اصلاح حضور | ناقص |
| تقویم شیفت پیشرفته | آینده |
| موتور قواعد payroll جدا از Service | آینده |
| مالیات YTD به‌عنوان تنها سیاست قانونی ایران | اختیاری است (`ytd_reconciliation`)؛ پیش‌فرض annualization ماهانه |
| لایه `Rules/` جدا | آینده |
| UI / Policy / Rate limit | خارج از پکیج؛ اپ میزبان |

این‌ها را الان به core اضافه نکنید.
