# سازمان

ساختار سازمانی از **دپارتمان درختی**، **سمت** و **انتساب کارمند به سمت** تشکیل شده است. شعبه (`branch_id`) یک کلید اختیاری برای multi-branch است؛ پکیج scope خودکار شعبه ندارد.

## دپارتمان

- درخت با `parent_id`؛ `path` و `level` خودکار به‌روز می‌شوند.
- حلقهٔ والد/فرزند ممنوع است (`InvalidOrganizationStructureException`).
- `head_employee_id` برای approver از نوع `department_head` لازم است.

## سمت

کاتالوگ شغل (`code`, `name`, `grade`). خود سمت تاریخچه ندارد؛ تاریخچه روی `EmployeePosition` است.

## انتساب سمت

هر کارمند حداکثر **یک سمت جاری** دارد (`current_key`). انتساب جدید سمت قبلی را می‌بندد.

## شعبه

`branch_id` روی کارمند، دپارتمان، سمت، شیفت، سند، workflow و دوره حقوق. فیلتر شعبه **opt-in** است (`scopeForBranch` روی بعضی مدل‌ها).

**آینده:** isolation اجباری tenant/شعبه داخل پکیج اضافه نمی‌شود؛ اپ میزبان باید Policy/Scope بگذارد.
