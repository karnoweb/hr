# مرخصی

درخواست مرخصی یک بازهٔ تاریخ است با نوع از `config('hr.leave.types')`.

## انواع پیش‌فرض

| کد | ویژگی مهم |
|----|-----------|
| `annual` | مانده سالانه، قابل انتقال |
| `sick` | نیاز به سند/پیوست برای approve |
| `unpaid` | بدون حقوق |
| `hourly` | سقف ساعت در ماه، بدون مانده روز |
| `marriage` | `fixed_days` + یک‌بار در استخدام |
| `maternity` | `fixed_days` |
| `bereavement` | `fixed_days` |

## مانده

`LeaveBalance` به ازای کارمند + سال + نوع. درخواست pending روزهای همان سال را **رزرو** می‌کند. بازه‌ای که سال را قطع کند بین دو سال تقسیم می‌شود.

در approve، مانده همان سال(های) overlapping کم می‌شود. cancel مرخصی تأییدشدهٔ آینده مانده را برمی‌گرداند.

Carry-over: `hr:carry-over-leave-balances`.

## همپوشانی

مرخصی pending/approved با مرخصی دیگر در همان بازه رد می‌شود. بازه‌های مجاور مجازند.

**آینده:** تخصیص پیشرفته تقویم جلالی به‌عنوان موتور جدا؛ الان `WorkingDayCalculator` با `hr.calendar` و تعطیلات کار می‌کند.
