# قرارداد

قرارداد رابطهٔ استخدام حقوقی است. هر کارمند حداکثر **یک قرارداد فعال** دارد (`active_key`).

## انواع

`permanent`, `temporary`, `project`, `part_time`, `internship`

## عملیات

| عمل | معنی |
|-----|------|
| `hire` | اولین قرارداد فعال |
| `renew` | بستن فعال و باز کردن قرارداد جدید (اتمیک) |
| `extend` | جلو بردن `end_date` قرارداد فعال |
| `terminate` | بستن قرارداد فعال |

`contract_number` در کل سیستم یکتا است.

**آینده:** قواعد خودکار حقوق بر اساس نوع قرارداد (پاره‌وقت/کارآموزی) هنوز تأیید کسب‌وکار نشده و پیاده نشده است.
